# Medir imóvel

App para medir cômodos parede por parede, montar a planta do imóvel e saber o que medir de novo.

**Usar pelo navegador (recomendado):** abra https://jfmjr1964-br.github.io/medir-imovel/ no Chrome do celular e toque em "Instalar app". Funciona sem internet e se atualiza sozinho.

**Arquivo de instalação para Android:** abra a página de [versões (Releases)](../../releases/latest) no celular, baixe `medir-imovel.apk` e toque no arquivo para instalar.

O app fica na pasta `www/`. A cada mudança enviada para o GitHub, o APK é gerado de novo automaticamente.
