# Medir imóvel

App para medir cômodos parede por parede, montar a planta do imóvel e saber o que medir de novo.

**Para instalar no Android:** abra a página de [versões (Releases)](../../releases/latest) no celular, baixe `medir-imovel.apk` e toque no arquivo para instalar.

O app fica na pasta `www/`. A cada mudança enviada para o GitHub, o APK é gerado de novo automaticamente.
